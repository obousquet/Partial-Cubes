Daisy Completion Defect on Daisy Cubes

Name: Daisy Completion Defect on Daisy Cubes

Invariant: Daisy Completion Defect

Class: Daisy Cubes

Quantifier: All Members

Value Type: Exact

Value: 0

Scope:

Finite nonempty daisy-cube representations.

Status: Established

Proof:

A daisy cube has a root $r$ for which it already equals $D_r(C)$, so no concepts need to be added. Conversely, zero added concepts means that $C=D_r(C)$ for a minimizing root and hence is a daisy cube.

Ordering Width of an Even Cycle

Class: Even Cycles

Parameters:

For $C_{2d}$ with $d\geq2$.

Scope:

Ordering width $\sigma$ under the database definition.

Status: Established

Proof:

The lower bound follows by taking the first prefix whose cyclic gaps all have length below $d$ and applying the first-two predecessor bound to the two new gaps. For the upper bound, order one semicircle consecutively, insert the midpoint of the remaining gap, and then finish arbitrarily; every minimal predecessor disagreement then has size at most $\lceil d/2\rceil$.
