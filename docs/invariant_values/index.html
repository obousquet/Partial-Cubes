Daisy Completion Defect on Daisy Cubes

Name: Daisy Completion Defect on Daisy Cubes

Invariant: Daisy Completion Defect

Class: Daisy Cubes

Quantifier: All Members

Value Type: Exact

Value: 0

Scope:

Finite nonempty daisy-cube representations.

Status: Established

Proof:

A daisy cube has a root $r$ for which it already equals $D_r(C)$, so no concepts need to be added. Conversely, zero added concepts means that $C=D_r(C)$ for a minimizing root and hence is a daisy cube.

Proof Source:

Edge Defect on Daisy Cubes

Name: Edge Defect on Daisy Cubes

Invariant: Edge Defect

Class: Daisy Cubes

Quantifier: All Members

Value Type: Exact

Value: 0

Scope:

Finite nonempty daisy-cube representations.

Status: Established

Proof:

In a down-set oriented toward its root, every one-coordinate step toward the root remains in the class, so there are no missing directed edges. Conversely, zero edge defect supplies a root with no missing inward edge; iterating inward steps makes the class a down-set.

Proof Source:

Ordering Width Is Unbounded on Partial Cubes

Name: Ordering Width Is Unbounded on Partial Cubes

Invariant: Ordering Width

Class: Partial Cubes

Quantifier: Supremum

Value Type: Unbounded

Value: unbounded

Parameters:

The even cycle $C_{2d}$ has $\sigma(C_{2d})=\lceil d/2\rceil-1$ for every $d\geq2$.

Scope:

Finite partial cubes.

Status: Established

Proof:

Every even cycle is a partial cube, and the displayed exact formula tends to infinity with $d$.

Proof Source:
