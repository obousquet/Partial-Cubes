USO Peeling Width of Hall's Maximum Class

Name: USO Peeling Width of Hall's Maximum Class

Invariant: USO Peeling Width

Example: Hall Maximum Class

Quantifier: Individual Object

Value Type: Range

Value: $2\le\nu(C_H)\le12$

Status: Established

Proof:

Hall's class has no corner and is therefore not dismantlable, so its peeling width is at least two. The published representation orientation has one nontrivial strongly connected component of twelve concepts and all remaining components are singletons, proving the upper bound.
