Cube Complement

Name: Cube Complement

Symbol:
\[C^{\mathrm c}\]

Arity: 1

Definition:

For a displayed binary class $C\subseteq\{0,1\}^n$, replace it by $\{0,1\}^n\setminus C$.

Category: Complement

Comments:

The ambient coordinate cube is part of the positioned input. Closure statements below exclude the empty complement when classes are required to be nonempty.
