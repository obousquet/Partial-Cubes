Concept Deletion

Name: Concept Deletion

Symbol:
\[C\setminus R\]

Arity: 1

Definition:

Delete an arbitrary set $R$ of concepts from a finite binary class $C$, retaining the same coordinate set and requiring the surviving class to be nonempty.

Category: Reduction

Comments:

This removes vertices rather than coordinates and is distinct from projection, conditioning, and pc-minors.
