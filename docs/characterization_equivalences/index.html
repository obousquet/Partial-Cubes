Daisy Down-Set and Zero-Defect Equivalence

Name: Daisy Down-Set and Zero-Defect Equivalence

Class: Daisy Cubes

Equivalent Characterizations:

  • Rooted Down-Set Embedding
  • Zero Daisy Completion Defect
  • Zero Edge Defect

Hypotheses:

Nonempty finite binary class, interpreted up to coordinate permutations and bit complements.

Statement:

A class has a rooted down-set representation if and only if its daisy completion defect vanishes, and if and only if its edge defect vanishes.

Status: Established

Proof:

The equality $\delta_D(C)=0$ says directly that $C=D_r(C)$ for some root. The equality $\eta(C)=0$ says that some orientation toward a minimizing root has no missing inward edge; repeated inward steps then show that $C$ is the rooted down-set $D_r(C)$.

Classical Learning-Space Equivalence

Name: Classical Learning-Space Equivalence

Class: Learning-Space Graphs

Equivalent Characterizations:

  • Accessible Union-Closed Family
  • Union-Closed Well-Graded Family
  • Closed Rooted Orientation

Hypotheses:

Finite nonempty set family, or finite connected graph in the orientation formulation.

Statement:

Finite antimatroids and finite learning spaces are the same set systems, and their one-inclusion graphs are exactly the partial cubes admitting a closed rooted orientation.

Status: Established

Proof:

Accessibility supplies deletion chains to the empty set. Unioning such chains with another feasible set produces tight paths, proving well-gradedness. Conversely, the first step of a tight path to the empty set proves accessibility. Under the partial-cube dictionary, union closure is equivalent to commutation of every pair of positive effective tokens, which is the closed rooted orientation condition.
