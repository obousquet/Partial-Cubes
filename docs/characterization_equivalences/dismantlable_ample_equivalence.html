Dismantlable-Ample Characterization Equivalence

Name: Dismantlable-Ample Characterization Equivalence

Class: Dismantlable Ample Classes

Equivalent Characterizations:

  • Ample-Prefix Ordering
  • Prefix-Isometric Ordering
  • Corner-Peeling Order
  • Acyclic Unique-Sink Orientation
  • Zero Ordering-Width Condition
  • Alexander-Dual Linear-Quotients Criterion

Hypotheses:

Finite nonempty binary family and its one-inclusion graph.

Statement:

Ample-prefix orders, prefix-isometric orders, reverse corner-peeling orders, acyclic unique-sink orientations, zero ordering width, and linear quotients of the Alexander-dual Yang ideal define the same class.

Status: Established

Proof:

For an isometric family, the first four order and orientation formulations are equivalent by the corner-peeling correspondence. An order has width zero precisely when every minimal predecessor disagreement is a singleton. The monomial-colon formula says that an order of the complementary-literal generators has linear quotients exactly when every earlier word has a previously inserted cube neighbor beginning a Boolean-interval path to it; this is equivalent to the same prefix-isometric, hence ample-prefix, order.
