Completion of Strict Dominance Certificates

Name: Completion of Strict Dominance Certificates

Invariants:

  • Separator Coefficient Ratio
  • Dominance Defect

Result Type: Algorithm

Statement:

A strict term-dominance certificate for any finite forbidden-pattern description of a nonempty binary class extends to its actual minimal missing patterns without changing the witness vectors. Rational or integer row weights remain rational or integer. Consequently the class has $\tau=0$.

Status: Established

Proof:

Eliminate coordinates by Davis--Putnam resolution. After normalizing each pivot weight to zero, merge compatible outside entries by their maximum. At either pivot bit the two original strict comparisons imply the resolvent comparison. Exact Boolean elimination ensures that each minimal missing pattern appears after eliminating its outside coordinates; retaining one derivation per pattern completes the shared certificate.
