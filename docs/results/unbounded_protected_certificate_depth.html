Protected-Certificate Depth Is Unbounded

Name: Protected-Certificate Depth Is Unbounded

Classes:

  • Ample Classes
  • Dismantlable Ample Classes

Invariants:

  • Protected-Certificate Depth

Operations:

  • Concept Deletion
  • Full Reduction
  • Partial-Cube Minor

Result Type: Construction

Statement:

For every $m\ge1$ there is an ample pc-minimal obstruction $K_m$ to dismantlable ampleness with $|K_m|=560\cdot2^m-493$, isometric dimension $m+23$, VC dimension $m+5$, empty protected core, and $d_{\mathrm{prot}}(K_m)\ge2^m$. The family is obtained by replacing one coordinate of a fixed $627$-concept obstruction by a block of size $m$. For $m>1$ it has negative coordinate reductions.

Status: Established

Proof:

A fixed $626$-concept root-cube completion has empty protected core, certified by an ordering in which every vertex's later-neighbour directions span a cube in the original family. Adding one compatible tip and replacing a nonincident coordinate by $m$ coordinates expands that tip into a punctured fibre of $2^m-1$ vertices. Block-relative transfer peels this fibre back to the expanded base. Every intermediate family still peels relatively to a target with empty protected core, so it also has empty protected core. Every corner-choice proof tree contains this branch and cannot stop even at the base, giving depth at least $2^m$. Block replacement preserves forbiddenness, and its order, isometric-dimension, and VC-dimension formulas give the stated parameters.
