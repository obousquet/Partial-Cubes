Exact Parent Criterion for One Missing Shattering Block

Name: Exact Parent Criterion for One Missing Shattering Block

Classes:

  • Ample Classes
  • Maximum-Generated Classes

Result Type: Recognition

Statement:

Suppose ample $C\subseteq\{0,1\}^X$ has $\operatorname{Sh}(C)=\{T:|T|\le r,\ J\nsubseteq T\}$ for $1\le|J|=q\le r<|X|$. There is one absent $J$-pattern $p$. With $I=\bigcap_{t\ne p}C[t]$, the following are equivalent: $C$ has a rank-$r$ maximum parent; $C$ lies in a rank-$r$ maximum class on $X$; and $I$ contains a maximum rank-$(r-q)$ class. Every envelope is $C\cup(S\times\{p\})$ for such an $S$. When these hold, the least parent rank is $r$ and the least auxiliary count is $r+1-q$, even allowing larger ranks.

Status: Established

Proof:

Projection after deleting any coordinate of $J$ is already maximum, forcing every new envelope word to occur at the single missing pattern $p$ and its private part to lie in $I$. Shattered supports containing $J$ are then exactly $J\cup T$ with $T$ shattered by the added section. The envelope is maximum precisely when that section is maximum of rank $r-q$. Minimum-section deletion supplies a parent, while VC dimension and the missing-pattern witness bound prove simultaneous optimality.
