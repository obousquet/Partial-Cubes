Exact Parameters and Minimality of Step-Two Obstructions

Name: Exact Parameters and Minimality of Step-Two Obstructions

Classes:

  • Ample Classes
  • Dismantlable Ample Classes
  • Convex-Treelike Partial Cubes

Operations:

  • Partial-Cube Minor

Result Type: Construction

Statement:

For every odd $n\ge9$, $\mathcal F_n$ is an ample partial cube with $10n+1$ vertices, VC dimension three, and isometric dimension $n$. It is periphery-free, while every proper pc-minor is cover-recursively peripheral. In each coordinate one oriented section defect consists of three vertices inducing a path.

Status: Established

Proof:

The shattered complex contains the empty set, $n$ singletons, $4n$ pair orbits, and $5n$ triple orbits, all with explicit positioned cubes; the forbidden alternating triple prevents higher shattering, so the count equals $10n+1$. The deletion rule makes the one-sided defect exactly a three-vertex path and a distant singleton witnesses the opposite noncontainment. For an elementary minor, a fixed 27-vertex one-section has a recursive peripheral decomposition. The zero section and contraction peel coordinates in the order $2,4,6,\ldots$ with duplicated sites that are pc-minors of that one-section. Oddness makes step two traverse every remaining coordinate; rotation handles all starting coordinates.
