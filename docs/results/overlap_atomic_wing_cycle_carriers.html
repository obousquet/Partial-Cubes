Both Wings of an Overlap-Atomic Obstruction Contain Cycles

Name: Both Wings of an Overlap-Atomic Obstruction Contain Cycles

Classes:

  • Ample Classes
  • Dismantlable Ample Classes

Operations:

  • Coordinate Conditioning
  • Full Reduction

Result Type: Invariant Law

Statement:

Let $H$ be an ample forbidden pc-minor whose full reduction in every nonempty coordinate set is dismantlable ample. For any active coordinate $e$, write $B_b=\rho_e^bH$, $A=B_0\cap B_1$, and $R_b=B_b\setminus A$. Then both induced relative-wing graphs $Q[R_0]$ and $Q[R_1]$ contain a cycle. Consequently $|R_0|,|R_1|\ge4$ and $|H|=2|A|+|R_0|+|R_1|\ge2|A|+8$.

Status: Established

Proof:

Overlap atomicity and pc-minimality put the overlap $A$ and both sections $B_0,B_1$ in the dismantlable-ample class, so each relative Yang module for $A\subseteq B_b$ is Cohen--Macaulay. If one relative-wing graph were a forest, the relative Yang forest theorem would give a relative shelling of that section over $A$. The Yang two-cone gluing dichotomy would then make $H$ corner-peelable, contradicting that it is forbidden. Both wings therefore contain cycles. Cube graphs are bipartite, so each cycle uses at least four vertices; the section identity $|H|=|B_0|+|B_1|=2|A|+|R_0|+|R_1|$ gives the order bound.
