Critical-Core Extension Normal Form for Ample Dismantlability Obstructions

Name: Critical-Core Extension Normal Form for Ample Dismantlability Obstructions

Classes:

  • Ample Classes
  • Dismantlable Ample Classes
  • Cornerless Ample Classes

Result Type: Construction

Statement:

Let $\mathfrak C_d^{\mathrm{col}}$ consist of full-transversal degree-$d$ ideals with a $d$-linear resolution, no linear-quotient order, and loss of $d$-linearity after deleting any minimal generator. Every ample pc-minimal obstruction to dismantlable ampleness is obtained from some $K\in\mathfrak C_d^{\mathrm{col}}$ by successively adjoining full-transversal generators $u_i$ with $K_{i-1}:u_i$ generated by variables, subject at the endpoint to irredundancy, failure of linear quotients, and linear quotients for all $3d$ elementary one-color images. Conversely every such endpoint is an obstruction. All intermediate ideals retain a $d$-linear resolution, and the extension word is empty exactly for cornerless obstructions.

Status: Established

Proof:

Adjoining $u_i$ fits into the standard colon exact sequence. A variable-generated colon bounds the quotient regularity by $d-1$, so each enlarged ideal remains $d$-linear. Conversely, delete generators from an obstruction while the remaining ideal stays $d$-linear. Lu's deletion theorem makes every reversed colon variable-generated. The terminal core cannot have linear quotients, since appending the reversed deletions would then give a linear-quotient order for the original obstruction. The ample corner-deletion criterion identifies immediate termination with cornerlessness; the algebraic pc-minor dictionary supplies the endpoint tests.
