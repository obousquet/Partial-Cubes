Static Repair-Antichain Formula

Name: Static Repair-Antichain Formula

Classes:

  • Partial Cubes

Operations:

  • Coordinate Projection
  • Coordinate Conditioning

Result Type: Invariant Law

Statement:

For an oriented defect $u\in\mathcal D_O(p,b)$, let $\mathcal H_O(p,b;u)$ be the antichain of inclusion-minimal difference supports between $u$ and possible mates in the base section. Under a layer minor state $\sigma$, the projected defect survives exactly when it matches every fixed coordinate and no repair support in $\mathcal H_O(p,b;u)$ is contained in the contracted coordinates. Hence $\sigma$ preserves nonperipherality of every displayed coordinate in both orientations exactly when each such orientation has a surviving original defect. A proper simultaneous descendant remains periphery-free exactly when a non-all-retained state with this property exists.

Status: Established

Proof:

A surviving defect cannot acquire a projected mate: such a mate would differ only in contracted coordinates and contain a minimal repair support there. Conversely, if the projected section has a defect, any preimage survives the fixed coordinates, and a repair support contained in the contractions would project a mate, a contradiction. Apply this equivalence to both orientations of the outer coordinate and every retained layer coordinate. Commutation of distinct-coordinate operations identifies the normalized simultaneous descendants with these states, after redundant constant coordinates are contracted.
