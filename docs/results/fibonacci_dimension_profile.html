Fibonacci-Dimension Formula, Bounds, and Product Laws

Name: Fibonacci-Dimension Formula, Bounds, and Product Laws

Classes:

  • Partial Cubes
  • Fibonacci Cubes
  • Trees

Invariants:

  • Fibonacci Dimension
  • Isometric Dimension
  • Semicube Coordinating-Path Number
  • Crossing Graph

Operations:

  • Cartesian Product

Result Type: Invariant Law

Statement:

A connected graph has finite Fibonacci dimension exactly when it is a partial cube. For a nontrivial partial cube $G$, $\operatorname{fdim}(G)=\operatorname{idim}(G)+p(X(G))-1$ and $\operatorname{idim}(G)\le\operatorname{fdim}(G)\le2\operatorname{idim}(G)-1$; equality in the upper bound holds exactly when the crossing graph is complete. Nontrivial partial cubes satisfy $\operatorname{fdim}(G\square H)=\operatorname{fdim}(G)+\operatorname{fdim}(H)+1$, and every tree satisfies $\operatorname{fdim}(T)=|E(T)|$.

Status: Established

Proof:

A Fibonacci-cube embedding is a hypercube embedding whose coordinate order prevents adjacent 1s. Choosing orientations and ordering the coordinates is equivalent to covering one semicube from each complementary pair by coordinating paths in $X(G)$; concatenating those paths requires one separator coordinate between consecutive paths. This gives the exact formula. The number of required paths lies between one and the isometric dimension, with the maximum characterized by complete crossing. Disjoint coordinate blocks with one separator prove the Cartesian-product law, and the tree formula follows because distinct tree edges form independent cuts.
