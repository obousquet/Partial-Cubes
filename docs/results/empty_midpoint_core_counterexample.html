Empty Unique-Midpoint Core Does Not Imply Peelability

Name: Empty Unique-Midpoint Core Does Not Imply Peelability

Classes:

  • Ample Classes
  • Dismantlable Ample Classes

Result Type: Construction

Statement:

There is a 292-concept ample forbidden pc-minor $H\subseteq Q_{12}$ for the dismantlable ample classes whose unique-midpoint core is empty. It has exactly one corner, 3959, with corner-cube support $\{4,7,11\}$. Deleting that corner gives a 291-concept cornerless ample forbidden pc-minor $\widehat G$ whose unique-midpoint core has order 76. Thus an ample forbidden pc-minor with empty unique-midpoint core need not peel, and it need not have a corner whose deletion leaves an empty core.

Status: Established

Proof:

The archived checker reconstructs both vertex sets and computes 291 and 292 shattered supports respectively, proving ampleness. It finds no corner in $\widehat G$ and only 3959 in $H$, so $\widehat G$ cannot peel and any peeling of $H$ would have to start by reaching $\widehat G$. It independently enumerates all 766 unique-midpoint constraints of $H$ and records a complete pruning order, while the same fixed-constraint calculation leaves a witnessed 76-vertex core in $\widehat G$. Finally, it verifies complete corner peelings for every restriction and contraction in all twelve coordinates of both families. Pc-minor closure of dismantlable ampleness then proves that both nonpeelable families are forbidden pc-minors.

Comments:

This disproves the converse of the unique-midpoint core obstruction. The sufficient direction, that a nonempty core forces nonpeelability, remains valid.
