Six-Cycle

Name: Six-Cycle

Symbol:
\[C_6\]

Object Type: Graph

Definition:

The cycle on six vertices, equivalently $Q_3$ with one antipodal pair of vertices deleted.

Properties:

It is $Q_3^{--}$, the first antipodally punctured hypercube. It is a two-dimensional partial cube, but it is neither ample, a daisy cube, nor a median graph; every proper pc-minor is ample, daisy, and median.

Four-Vertex Path

Name: Four-Vertex Path

Symbol:
\[P_4\]

Object Type: Graph

Definition:

Take $P=\{p\}$, $R=\{q,e\}$, $A=\{q\}$, and $\mathcal W=\{\varnothing,\{q\},\{e\}\}$ in the construction $O(P,R,A;\mathcal W)$.

Properties:

The resulting graph is $P_4$. It is a path, tree, median graph, maximum class, and learning-space graph. It is neither a star nor a daisy cube, and every proper pc-minor is a path and a star.

Learning-Space Conditioning to a Three-Leaf Star

Name: Learning-Space Conditioning to a Three-Leaf Star

Object Type: Construction

Definition:

Let $\mathcal A=(2^{\{1,2,3\}}\setminus\{\{1\}\})\cup\{\{1,2,3,4\}\}$. This is an accessible union-closed family. Condition on item $1$ being present and then delete coordinate $1$.

Properties:

The conditioned one-inclusion graph is $K_{1,3}$. The parent is a learning-space graph, while the star admits no closed rooted orientation and is not a learning-space graph.

Vertex-Deleted Three-Cube

Name: Vertex-Deleted Three-Cube

Symbol:
\[Q_3^-\]

Object Type: Graph

Definition:

The subgraph of $Q_3$ induced by $\{0,1\}^3\setminus\{111\}$; every choice of the deleted cube vertex is isomorphic to this one.

Properties:

It is a partial cube, a daisy cube, an ample class, and a convex-geometry ideal, but it is not median: the coordinatewise majority of $110,101,011$ is the missing vertex $111$. Every proper pc-minor is median.

A Nonmaximum Conditioning of a Maximum Class

Name: A Nonmaximum Conditioning of a Maximum Class

Object Type: Construction

Definition:

Let $K=\{\varnothing,\{1\},\{2\},\{3\}\}$ and $M=K\cup\{A\cup\{z\}:A\in K\}\cup\{\{1,2\},\{1,3,z\},\{2,3,z\}\}$. Condition $M$ on $z=0$.

Properties:

$M$ has $11=1+4+\binom42$ members and VC dimension $2$, so it is maximum. Its $z=0$ section is $K\cup\{\{1,2\}\}$, which has VC dimension $2$ but only five members on three active coordinates, below the maximum size seven. Thus the section is ample but not maximum.

Three-Cube

Name: Three-Cube

Symbol:
\[Q_3\]

Object Type: Graph

Definition:

The graph on all binary triples, with two triples adjacent when they differ in one coordinate.

Properties:

It is a hypercube, median graph, maximum class, ample class, and partial cube. Its VC dimension and isometric dimension are both three, so it is not a two-dimensional partial cube and is not an ample class of rank at most two. Every proper pc-minor has VC dimension at most two.

Symbol:

Object Type: Graph

Definition:

The cycle graph on eight vertices, canonically embedded in $Q_4$ by flipping coordinates $1,2,3,4,1,2,3,4$ in cyclic order.

Antipodal Pair Family

Name: Antipodal Pair Family

Symbol:
\[A_n=\{0^n,1^n\}\]

Object Type: Family

Definition:

For each integer $n\geq1$, the two-word class consisting of the two antipodal vertices of $Q_n$.

Parameters:

Integer $n\geq1$.

Properties:

Its ordering width is $n-1$. Its optimal daisy completion adds $2^{\lfloor n/2\rfloor}+2^{\lceil n/2\rceil}-3$ concepts, attaining the sharp completion bound. For $n>1$ its one-inclusion graph is disconnected, so it is not a partial cube.

Proof Source:

Disjoint Two-Support Family

Name: Disjoint Two-Support Family

Symbol:
\[E_k\]

Object Type: Family

Definition:

Partition $[2k]$ into pairs $B_1,\ldots,B_k$ and take the $k$ concepts whose supports are the individual blocks $B_i$.

Parameters:

Integer $k\geq2$.

Properties:

It has ordering width three, Yang depth defect $k+1$ over every field, and daisy completion defect at most $2k+1$. Thus an exponential lower bound on daisy defect in terms of Yang depth fails for general concept classes.

Weight-at-Most-Two Family

Name: Weight-at-Most-Two Family

Symbol:
\[L_{n,2}\]

Object Type: Family

Definition:

The binary class consisting of all supports in $[n]$ of cardinality at most two.

Parameters:

Integer $n\geq3$.

Properties:

It is a maximum daisy class of VC dimension two and ordering width zero. Its majority closure is the full cube $Q_n$, so its majority completion defect is $2^n-1-n-\binom n2$, which is unbounded with $n$.

Proof Source:
