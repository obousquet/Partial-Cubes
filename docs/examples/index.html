Six-Cycle

Name: Six-Cycle

Symbol:
\[C_6\]

Object Type: Graph

Definition:

The cycle on six vertices, equivalently $Q_3$ with one antipodal pair of vertices deleted.

Properties:

It is $Q_3^{--}$, the first antipodally punctured hypercube. It is a two-dimensional partial cube, but it is neither ample, a daisy cube, nor a median graph; every proper pc-minor is ample, daisy, and median.

Four-Vertex Path

Name: Four-Vertex Path

Symbol:
\[P_4\]

Object Type: Graph

Definition:

Take $P=\{p\}$, $R=\{q,e\}$, $A=\{q\}$, and $\mathcal W=\{\varnothing,\{q\},\{e\}\}$ in the construction $O(P,R,A;\mathcal W)$.

Properties:

The resulting graph is $P_4$. It is a path, tree, median graph, maximum class, and learning-space graph. It is neither a star nor a daisy cube, and every proper pc-minor is a path and a star.

Object Type: Construction

Definition:

A Nonmaximum Conditioning of a Maximum Class

Name: A Nonmaximum Conditioning of a Maximum Class

Object Type: Construction

Definition:

Let $K=\{\varnothing,\{1\},\{2\},\{3\}\}$ and $M=K\cup\{A\cup\{z\}:A\in K\}\cup\{\{1,2\},\{1,3,z\},\{2,3,z\}\}$. Condition $M$ on $z=0$.

Properties:

$M$ has $11=1+4+\binom42$ members and VC dimension $2$, so it is maximum. Its $z=0$ section is $K\cup\{\{1,2\}\}$, which has VC dimension $2$ but only five members on three active coordinates, below the maximum size seven. Thus the section is ample but not maximum.

CompressionSchemes:partitionable_yang_complexes.tex?#ex:nonmaximum-maximum-generated-pc-minor

Antipodal Pair Family

Name: Antipodal Pair Family

Symbol:
\[A_n=\{0^n,1^n\}\]

Object Type: Family

Definition:

For each integer $n\geq1$, the two-word class consisting of the two antipodal vertices of $Q_n$.

Parameters:

Integer $n\geq1$.

Properties:

Its ordering width is $n-1$. Its optimal daisy completion adds $2^{\lfloor n/2\rfloor}+2^{\lceil n/2\rceil}-3$ concepts, attaining the sharp completion bound. For $n>1$ its one-inclusion graph is disconnected, so it is not a partial cube.

Pentagonal Obstruction

Name: Pentagonal Obstruction

Symbol:
\[\mathcal P_5\]

Object Type: Set Family

Definition:

On the cyclic ground set $[5]$, take the empty set, all five singletons, the five edges of $C_5$, and the five complements of those edges. In low-bit integer encoding the family is $\{0,1,2,3,4,6,7,8,12,14,16,17,19,24,25,28\}$.

Properties:

A sixteen-vertex realizable maximum and ample class of VC dimension two and isometric dimension five. It is the sign-pattern class of the five tangent lines of a regular pentagon. It has a corner peeling but no peripheral coordinate; every elementary pc-minor belongs to $\mathcal R_{\mathrm{per}}$. Thus it witnesses both $\mathcal R_{\mathrm{per}}\subsetneq\mathcal D_{\mathrm{amp}}$ and $\mathcal R_{\mathrm{amp}}\nsubseteq\mathcal R_{\mathrm{per}}$.

Incompatible Realizable Gated Amalgam

Name: Incompatible Realizable Gated Amalgam

Symbol:
\[X_{33}\]

Object Type: Set Family

Definition:

On coordinates $(a_1,a_2,b_1,b_-,i,j,b_+)$ in low-bit order, take the 33 words $\{0,1,2,3,16,17,18,19,20,24,25,28,32,33,34,35,36,37,40,42,44,48,52,56,60,80,82,84,96,97,100,112,116\}$. Its sections $A=X_{b_+=0}$ and $B=X_{b_-=0}$ each have 25 words and meet in the common 17-word section $D=X_{b_-=b_+=0}$.

Properties:

The union and both pieces are ample partial cubes. Each piece is gated in the union, is downward closed in its private coordinate, and has an exact rational separation certificate of margin at least $1/240$. Their section-row cycle ratios are respectively $1/3$ and $3$, forcing disjoint extension spaces; hence the 33-word gated amalgam has separation margin zero and is not realizable ample.
