Two Individually Ineffective Tips That Cooperatively Restore an Endpoint

Name: Two Individually Ineffective Tips That Cooperatively Restore an Endpoint

Object Type: Construction

Definition:

Use the 289-concept rooted core $B$, repairing side tips $\alpha=128$ and $\delta=290$, and the third ample tip $\gamma=604$ with acquired support $\{5,6,9,10\}$. In the resulting 870-concept partially replicated-tip factor $S$, add $u=(\gamma,10)$ and $v=(\gamma,11)$.

Parameters:

$S$ has $870$ concepts; each single-tip extension has $871$ and the double extension has $872$. In integer encoding the new words are $2417,2419$.

Properties:

Both $S\cup\{u\}$ and $S\cup\{v\}$ remain rooted factors, but $S\cup\{u,v\}$ peels to the original root. Each first addition has acquired support bitmask $6528$ of size four; the second addition has support $6530$ of size five. The two added words are adjacent and have coincident initial supports.
