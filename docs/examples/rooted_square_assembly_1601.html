The 1601-Concept Rooted Square Assembly

Name: The 1601-Concept Rooted Square Assembly

Object Type: Construction

Definition:

Use the certified 289-concept first factor with marked coordinate 1, whose marked contraction has order 224 and section intersection has order 65. Use a disjoint certified 289-concept rooted factor as the second input and choose a square hole adjacent to 00.

Parameters:

The output has $3\cdot224+65+3\cdot289-3=1601$ concepts in dimension 25. More generally this first factor gives order $3|B|+734$ in dimension $\dim(B)+13$.

Properties:

The first factor has 22 certified edge-relative elementary orders and three projected endpoint orders. With the archived second factor rooted at 0, the output is an ample forbidden pc-minor with exactly two corners, because that root is not a corner and the factor has one nonroot corner. The verifier checks the attachment identity, all 24 rooted minor orders for the second factor, and the predicted corner set; minor minimality follows uniformly from the theorem.
