A 909-Concept Obstruction with a Four-Vertex-Path Reduction

Name: A 909-Concept Obstruction with a Four-Vertex-Path Reduction

Object Type: Construction

Definition:

Take the 289-concept unique-corner block $B$ with path $H=2-0-4-5$, attach a disjoint-coordinate copy $(A,2)$ of the 289-concept rooted factor at the first endpoint, attach the certified 330-concept edge piece $P$ along $\{4,5\}$, put $U=B\cup A\cup P$ and $S=H\cup A\cup P$, and form $X=(B\times\{0\})\cup(S\times\{1\})$.

Parameters:

$|U|=905$, $|S|=620$, $|X|=909$, and $X$ has $37$ active coordinates.

Properties:

$X$ is ample and not corner-peelable, while its contraction, both sections, and all $111$ elementary proper pc-minors are corner-peelable. Hence it is an ample pc-minimal obstruction. Its fresh-coordinate reduction is the path $2-0-4-5$, so that coordinate class has exactly four edges.
