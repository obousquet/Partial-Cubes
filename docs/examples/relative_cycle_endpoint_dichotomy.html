A Residual Six-Cycle Whose Designated Vertex Can Be Neither First Nor Last

Name: A Residual Six-Cycle Whose Designated Vertex Can Be Neither First Nor Last

Object Type: Construction

Definition:

In $Q_4$, let $A=\{0,1,2,3,4,5,6,8,10,11\}$ and $H=\{0,8,10,11\}$. The exclusive graph on $A\setminus H$ is the induced cycle $(1,3,2,6,4,5)$.

Properties:

Both $H$ and $A$ are ample. The designated residual vertex 1 cannot be added first because $H\cup\{1\}$ omits both intermediates between 1 and 11, and it cannot be deleted first because $A\setminus\{1\}$ omits both intermediates between 3 and 5. Nevertheless $A$ peels to $H$ in the order $(5,6,4,1,3,2)$. Thus the relative leaf first-or-last dichotomy does not apply vertexwise to residual cycles; this example is not an obstruction to relative cycle peeling.
