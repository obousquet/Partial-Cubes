Terminal Empty-Core Antipodal Repair Towers

Name: Terminal Empty-Core Antipodal Repair Towers

Symbol:
\[X_r\]

Object Type: Family

Definition:

For the certified cornerless 291-concept seed $G\subseteq Q_{12}$ and $r\ge1$, let $X_r=(G\times Q_r)\cup(\{91\}\times(Q_r\setminus\{0^r\}))\cup(\{157\}\times(Q_r\setminus\{1^r\}))$. The two repair tips acquire supports $\{1,2,5,6\}$ and $\{1,2,7,8\}$ in one-based coordinate notation.

Parameters:

Integer $r\ge1$.

Properties:

Each $X_r$ is an ample forbidden pc-minor for dismantlable ampleness, is corner-descent-terminal, has isometric dimension $12+r$, order $293\cdot2^r-2$, exactly $2r$ corners, and empty unique-midpoint core. For $r=1$, deleting either of its two corners produces a family whose unique-midpoint core has order 76.
