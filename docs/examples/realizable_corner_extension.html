Realizable Twenty-Seven-Word Corner Extension

Name: Realizable Twenty-Seven-Word Corner Extension

Symbol:
\[D_{27}\]

Object Type: Set Family

Definition:

On coordinates $(a_1,a_2,b_1,b_2,i,j)$ in low-bit order, take the 26-word four-section class $E_{26}$ and add $w=(1,0,0,0,1,1)$, encoded by 49.

Properties:

It is ample and affine-convex realizable in $R^6$, has 27 words and VC dimension three, and $w$ is contained in the unique maximal cube with free coordinates $\{a_1,i,j\}$. Deleting $w$ gives the nonrealizable ample class $E_{26}$.
