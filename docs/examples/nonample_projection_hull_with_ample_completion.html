Ample Projection Data Whose Maximal Intersection Is Nonample

Name: Ample Projection Data Whose Maximal Intersection Is Nonample

Object Type: Set Family

Definition:

In integer-encoded $Q_4$ with coordinate zero least significant, take $D=Q_4\setminus\{0,1,3,7,15\}$ and selected coordinates $K=\{0,3\}$.

Parameters:

$D$ has $11$ concepts and shatters exactly the eleven supports of size at most two.

Properties:

$D$ is ample. The largest family with the same selected one-coordinate projections is $\bigcap_{i\in K}\pi_i^{-1}(\pi_iD)=D\cup\{3\}$, which has $12$ vertices but $13$ shattered supports and is therefore nonample. Thus ampleness of this maximal intersection is not a necessary test for the existence of an ample common completion.
