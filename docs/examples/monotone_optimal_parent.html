Downset with Simultaneously Optimal Parent Parameters

Name: Downset with Simultaneously Optimal Parent Parameters

Symbol:
\[C_{8}\subset Q_4\]

Object Type: Set Family

Definition:

In binary integer notation on weights $1,2,4,8$, take $C=\{0,1,2,3,4,5,6,8\}$: every proper subset of $\{1,2,3\}$ together with the singleton $\{4\}$.

Properties:

Its VC dimension and least minimal-nonface size are both two, so its minimum parent rank is two and its minimum auxiliary count is one. With auxiliary weight 16, the 16-word class $M=C\cup\{16+x:x\in\{0,1,2,4,8,9,10,12\}\}$ is an explicit rank-two maximum parent attaining both minima.
