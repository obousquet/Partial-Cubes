VC-Saturated Projection Witness

Name: VC-Saturated Projection Witness

Symbol:
\[H_{\mathrm{pv}}\]

Object Type: Set Family

Definition:

$\{00000,00001,00101,01001,01101,01111,10101,10110,10111,11001,11010,11011,11101,11111\}\subseteq\{0,1\}^5$.

Properties:

It is VC-saturated. Deleting the middle coordinate yields a VC-dimension-two class that remains of VC dimension two after adding $1000$, so the projection is not VC-saturated.
