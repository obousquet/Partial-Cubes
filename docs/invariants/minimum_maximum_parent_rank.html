Minimum Maximum-Parent Rank

Name: Minimum Maximum-Parent Rank

Symbol:
\[h(C)\]
Definition:

For a nonempty proper maximum-generated class $C$, $h(C)=\min\{r:(r,s)\in\mathcal F(C)\text{ for some }s\}$ is the least rank of a maximum class having $C$ as a coordinate section.

Status: Established

Domain: Maximum-Generated Classes

Codomain: Nonnegative integers

Normalization:

The visible positioned coordinate set is retained; auxiliary coordinates alone may be added.

Category: Combinatorial

Isomorphism Invariant: No

Comments:

Always at least the VC dimension. Constant visible coordinates can affect related auxiliary costs even when the one-inclusion graph is unchanged.
