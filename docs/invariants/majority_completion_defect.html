Majority Completion Defect

Name: Majority Completion Defect

Symbol:
\[\delta_{\mathrm{med}}\]
Definition:

For a finite nonempty binary class $C$, let $\operatorname{med}(C)$ be its least coordinatewise-majority-closed superclass in the same cube and set $\delta_{\mathrm{med}}(C)=|\operatorname{med}(C)|-|C|$.

Status: Established

Codomain: Nonnegative integers

Normalization:

Constant coordinates are retained but do not change the value. On connected partial cubes the defect is the minimum number of additions needed for an isometric median superclass.

Category: Combinatorial

Isomorphism Invariant: Yes
