Every Theta Class Is Peripheral

Name: Every Theta Class Is Peripheral

Class: Daisy Cubes

Type: Intrinsic Metric

Model: Graph

Criterion:

A finite partial cube is a daisy cube exactly when every $\Theta$-class $E_x$ is peripheral: for at least one side $\epsilon\in\{0,1\}$, the boundary $U_x^\epsilon$ equals the whole semicube $W_x^\epsilon$.

Hypotheses:

Finite partial cube; no root or hypercube embedding is chosen.

Status: Established

Recognition Complexity:

$O(n^2)$ on an arbitrary $n$-vertex input, including construction of a proper down-set labelling when the test succeeds.
