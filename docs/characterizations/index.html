Isometric Hypercube Embedding

Name: Isometric Hypercube Embedding

Class: Partial Cubes

Type: Definitional

Model: Graph

Criterion:

A connected graph $G$ belongs to the class when there are an integer $n$ and an injective map $\varphi\colon V(G)\to\{0,1\}^n$ such that $d_G(u,v)=d_{Q_n}(\varphi(u),\varphi(v))$ for every pair of vertices $u,v$.

Hypotheses:

Connected graph; the frozen survey formulation uses a finite-dimensional hypercube $Q_n$.

Status: Established

Proof Source:

PartialCubes:papers/survey/main.tex?#sec:partial-cube-basics

Comments:

This is the primary catalogue definition. The least possible n is the isometric dimension of G.

Bipartite Graph with Transitive Theta Relation

Name: Bipartite Graph with Transitive Theta Relation

Class: Partial Cubes

Type: Intrinsic Metric

Model: Graph

Criterion:

A connected graph $G$ belongs to the class exactly when $G$ is bipartite and the Djoković–Winkler relation $\Theta$ on $E(G)$ is transitive.

Hypotheses:

Connected graph. For edges $xy$ and $uv$, the relation is defined by $xy\mathrel{\Theta}uv$ when $d_G(x,u)+d_G(y,v)\ne d_G(x,v)+d_G(y,u)$.

Status: Established

References:

[BandeltChepoi08survey] (Theorem 8.3)

Proof Source:

PartialCubes:papers/survey/main.tex?#sec:partial-cube-basics

Comments:

This criterion is intrinsic: it does not assume a chosen hypercube embedding.

Shattering-Extremal Equality

Name: Shattering-Extremal Equality

Class: Ample Classes

Type: Definitional

Model: Set Family

Criterion:

A family $H\subseteq 2^X$ is ample when $\operatorname{sstr}(H)=\operatorname{str}(H)$, where $\operatorname{str}(H)$ and $\operatorname{sstr}(H)$ are its shattered and strongly shattered coordinate sets.

Hypotheses:

$X$ is finite.

Status: Established

References:

[BandeltCDK06]

Proof Source:

PartialCubes:papers/survey/main.tex?#sec:vcsetfam

Comments:

The terms lopsided and shattering-extremal are synonymous with ample in this formulation.

Sauer--Shelah--Perles Bound Equality

Name: Sauer--Shelah--Perles Bound Equality

Class: Maximum Classes

Type: Definitional

Model: Set Family

Criterion:

A family $H\subseteq 2^X$ of VC dimension $d$ is maximum when $|H|=\sum_{i=0}^{d}\binom{|X|}{i}$.

Hypotheses:

$X$ is finite and $d=\dim_{\mathrm{VC}}(H)$.

Status: Established

Invariants:

  • VC Dimension

Proof Source:

PartialCubes:papers/survey/main.tex?#sec:vcsetfam

Comments:

Maximum is equality in the Sauer--Shelah--Perles bound, rather than maximality under inclusion.

Rooted Down-Set Embedding

Name: Rooted Down-Set Embedding

Class: Daisy Cubes

Type: Definitional

Model: Mixed

Criterion:

A graph $G$ is a daisy cube when there are a root $u$, a finite coordinate set $X$, and an isometric embedding $\varphi\colon V(G)\to2^X$ such that $\varphi(u)=\varnothing$ and $\varphi(V(G))$ is a down-set under inclusion.

Hypotheses:

$G$ is connected and finite.

Status: Established

References:

[klavvzar2019daisy]

Proof Source:

PartialCubes:papers/survey/main.tex?#def:daisy-cube

Comments:

Equivalently, the image is the union of the Boolean intervals from the empty set to its inclusion-maximal members.

Downward-Closed Expansion Sequence

Name: Downward-Closed Expansion Sequence

Class: Daisy Cubes

Type: Generative

Model: Graph

Criterion:

A connected graph is a daisy cube exactly when it can be obtained from $K_1$ by a sequence of peripheral expansions whose duplicated sites are downward closed in the rooted coordinate order at each step.

Hypotheses:

Finite connected graph; each step uses the root and embedding carried by the construction.

Status: Established

References:

[taranenko2020daisy] (Theorem 2.8)

Proof Source:

PartialCubes:papers/survey/main.tex?#thm:daisy-expansions

Comments:

The survey calls these $\leq$-expansions. Requiring the duplicated site to be convex selects the median daisy cubes.
