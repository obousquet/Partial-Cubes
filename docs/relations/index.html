Daisy Cubes Are Partial Cubes

Name: Daisy Cubes Are Partial Cubes

Subject: Daisy Cubes

Object: Partial Cubes

Relation: Inclusion

Status: Established

Scope:

Finite connected graphs.

Statement:

Every daisy cube is a partial cube.

Proof:

A down-set induces an isometric subgraph of its Boolean cube: if $A$ and $B$ lie in the down-set, first delete the elements of $A\setminus B$ and then add the elements of $B\setminus A$ through subsets of $B$. This gives a path of length $|A\mathbin\triangle B|$, equal to their Hamming distance.

References:

[klavvzar2019daisy] (Proposition 2.1)

Proof Source:

Daisy Cubes Are Ample

Name: Daisy Cubes Are Ample

Subject: Daisy Cubes

Object: Ample Classes

Relation: Inclusion

Status: Established

Scope:

Finite down-set representations of daisy cubes.

Statement:

Every daisy cube has an ample set-family representation.

Proof:

Let $D\subseteq2^X$ be a down-set. If $T$ is shattered by $D$, some member of $D$ contains $T$, so downward closure gives $T\in D$. Conversely, every $T\in D$ is strongly shattered because the full face $2^T$ lies in $D$. Thus the shattered and strongly shattered sets both equal $D$.

References:

[BandeltCDK06]

Proof Source:

PartialCubes:papers/daisy-cubes/sections/daisy_pc_minors_body.tex?#sec:class-position

Comments:

This records existence of an ample representation; root and coordinate orientations are not canonical.

Learning-Space Graphs Are Partial Cubes

Name: Learning-Space Graphs Are Partial Cubes

Subject: Learning-Space Graphs

Object: Partial Cubes

Relation: Inclusion

Status: Established

Scope:

Finite learning spaces and their one-inclusion graphs.

Statement:

Every learning-space graph is a partial cube.

Proof:

For states $A,B$, accessibility gives deletion chains and union closure transports them to tight paths from $A$ through $A\cup B$ to $B$. The path length is $|A\mathbin\triangle B|$, so the one-inclusion graph is isometric in its Boolean cube.

Ample Classes Are Strictly Partial Cubes

Name: Ample Classes Are Strictly Partial Cubes

Subject: Ample Classes

Object: Partial Cubes

Relation: Strict Inclusion

Status: Established

Scope:

Finite ample set families and their one-inclusion graphs.

Statement:

The one-inclusion graph of every finite ample class is a partial cube, and the inclusion is strict.

Witnesses:

  • Six-Cycle

Proof:

One equivalent form of ampleness states that every strong projection has an isometric one-inclusion graph. Applying this to the class itself shows that graph distance equals Hamming distance on every pair of its members, so its one-inclusion graph embeds isometrically in the ambient hypercube. Strictness is witnessed by the six-cycle $C_6$: it is a partial cube, but it is not ample.

Maximum Classes Are Strictly Ample

Name: Maximum Classes Are Strictly Ample

Subject: Maximum Classes

Object: Ample Classes

Relation: Strict Inclusion

Status: Established

Scope:

Finite set families.

Statement:

Every maximum class is ample, and the containment is strict.

Witnesses:

  • Two-Word VC Implication Witness

Proof:

Let $H\subseteq2^X$ have VC dimension $d$. If $H$ is maximum, then $|H|=\sum_{i=0}^{d}\binom{|X|}{i}$. Every shattered set has size at most $d$, so $|\operatorname{str}(H)|\leq\sum_{i=0}^{d}\binom{|X|}{i}$. The sandwich inequality $|H|\leq|\operatorname{str}(H)|$ therefore holds with equality, which is equivalent to ampleness.
