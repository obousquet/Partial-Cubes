Matroid Flat Classes Are Not Conditioning-Closed

Name: Matroid Flat Classes Are Not Conditioning-Closed

Class: Matroid Flat Classes

Operation: Coordinate Conditioning

Result Type: Not Closed Under

Status: Established

Statement:

A nonempty coordinate conditioning of a matroid flat class need not be a matroid flat class.

Witnesses:

  • Flat Class of $U_{1,2}$

Proof:

Conditioning $\{00,11\}$ at the first coordinate to zero gives $\{0\}$ on a one-element ground set. Every matroid ground set is itself a flat, so a flat family on that ground set must contain $\{1\}$.
