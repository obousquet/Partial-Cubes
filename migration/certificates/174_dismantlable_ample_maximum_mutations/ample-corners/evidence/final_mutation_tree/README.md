# Leaf fibers of the Hall double reductions

The12 marked Hall controls all reduce in their two-coordinate type to a
maximum rank-one class:11 vertices and10 edges, with every remaining
coordinate used by exactly one edge. Each tree is a path with two leaves.
For every leaf and every direction other than its tree edge and the two
reduction directions, save the part of its square that has a neighbor in
that direction. All these sets are proper, but at each leaf two suffice
to cover the entire square. The minimum covering number is2 at all24 leaves.

This reuses known Hall obstructions to test a proposed lifting argument.
It does not prove existence below267 or exclude a dimension-sensitive
argument distinguishing2+5 from Hall's2+6. The local coverage equivalence
is proved in the main writeup, rem:damp-final-mutation-tree-leaves.
Source snapshots and fingerprints are retained. Reproduce using
papers/ample-corners/scripts/analyze_final_mutation_tree.py under the
repository memory/CPU guardrails.
